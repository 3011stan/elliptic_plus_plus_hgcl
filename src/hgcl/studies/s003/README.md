# Código do Estudo 003

Novos módulos específicos do `S003-TxGCL` pertencem a este pacote. Não importe
configurações ou conceitos do Estudo 002 por conveniência. Componentes históricos
somente poderão ser reutilizados após uma tarefa explícita de extração, testes de
compatibilidade e registro em `docs/studies/s003/decisions.md`.
